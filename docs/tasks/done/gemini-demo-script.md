## 目标

新建 `docs/DEMO_SCRIPT.md`，写一份 5–8 分钟的现场演示脚本，按“Daily → Interaction → Guidance → 统一时间线/总结”的顺序：

- 每一步写清：演示者操作、屏幕上应看到的结果、一句讲解词。
- Guidance 部分只使用明确句式（例如“今天上午9点宝宝喝了120ml奶”“今天宝宝喝了多少奶？”），并准备一句模糊句（例如“宝宝刚才喝了点奶”），用来展示 AI 会追问。
- 写一节“现场故障预案”：模型响应慢、Tailscale 断开、摄像头无画面时各自怎么说、怎么切换。
- 定位为课程原型：不承诺医疗用途，不出现“诊断/保证安全”等表述。
- 统一时间线和每日总结标记为“开发中”，等 Claude 告知接口完成后再补具体步骤。
